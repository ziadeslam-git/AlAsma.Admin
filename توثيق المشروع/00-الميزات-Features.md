# ميزات النظام (Features)

**AlAsma.Admin — الأسمى للنشر والتوزيع**

## 1. المصادقة والأمان
- [x] تسجيل الدخول بـ **الكود + كلمة المرور** (بدون إيميل)، مع عدم كشف أيهما الخاطئ.
- [x] تشفير كلمات المرور بـ **BCrypt**.
- [x] جلسة بالكوكي لمدة 8 ساعات متجددة، وتحويل تلقائي حسب الدور.
- [x] 3 أدوار: **SuperAdmin / Admin / Author** مع حماية `[Authorize(Roles=...)]` على الـ Controllers والأكشنز.
- [x] حماية النماذج بـ Anti-Forgery Token.
- [x] لا يوجد تسجيل ذاتي ولا «نسيت كلمة المرور» (قرار متطلبات).
- [x] المؤلف لا يستطيع رؤية أو تصدير بيانات غيره.
- [x] صفحات أخطاء عربية (403 / 404 / 500) دون كشف تفاصيل تقنية.
- [x] **تحديد معدل محاولات الدخول** (8 محاولات في الدقيقة لكل IP، ثم 429).
- [x] **إعادة التحقق من المستخدم في كل طلب**: الحساب المحذوف أو الذي تغيّر دوره يفقد الوصول فوراً.
- [x] سياسة افتراضية تطلب تسجيل الدخول لأي صفحة لا يُصرَّح لها صراحةً بالدخول المجهول.
- [x] كوكي `HttpOnly` و`SameSite=Lax` + ترويسات أمان (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`).
- [x] التحقق من الحد الأدنى لكلمة المرور (6) عند الإنشاء والتعديل، ومنع إعادة استخدام كود مؤلف محذوف.

## 2. إدارة المستخدمين
- [x] SuperAdmin واحد يُنشأ بالـ Seeding فقط.
- [x] إضافة وتعديل وحذف ناعم (Soft Delete) للمديرين Admins — SuperAdmin فقط.
- [x] إضافة وتعديل وحذف ناعم للمؤلفين — SuperAdmin فقط.
- [x] الأدمن يعرض المؤلفين وصفحاتهم فقط (بدون تعديل أو حذف).
- [x] كود المؤلف فريد ولا يتغير بعد الإنشاء.

## 3. العقود
- [x] تاريخ بداية ونهاية العقد، والمصروفات الأساسية `BasicFees`.
- [x] **حالة العقد** تلقائياً: نشط / ينتهي قريباً (≤ 20 يوم) / منتهي / غير محدد.
- [x] **الأيام المتبقية** وعداد تنازلي حي في لوحة المؤلف.
- [x] قائمة المؤلفين الذين ينتهي عقدهم قريباً في لوحة الإدارة.

## 4. المبيعات
- [x] تسجيل عملية بيع: الكتاب، المؤلف، السعر، الكمية، مصروف النسخة، المنفذ، التاريخ.
- [x] **حساب تلقائي للإجمالي** في الخادم فقط، مع معاينة فورية للمستخدم قبل الحفظ.
- [x] بحث بأربعة حقول (الكتاب / المؤلف / كود المؤلف / المنفذ) + ترقيم صفحات (10 في الصفحة) كله داخل SQL.
- [x] مؤشرات: عدد العمليات، إجمالي المبالغ (صافي)، الكتب المباعة، إجمالي المصروفات.
- [x] تعديل عملية بيع (Admin / SuperAdmin) وحذف نهائي (SuperAdmin فقط).
- [x] **تعديل جماعي للمصروفات** على نتائج البحث الحالية (SuperAdmin فقط).

## 5. العمليات والمصروفات التشغيلية
- [x] تسجيل مصروف (طباعة، تصميم، إيجار...) مرتبط بمؤلف/كتاب أو «نفقة عامة».
- [x] إجمالي العملية = تكلفة الوحدة × الكمية.
- [x] بحث بأربعة حقول + ترقيم.
- [x] مؤشرات: إجمالي المصاريف، إجمالي المبيعات، **صافي الأرباح**.
- [x] تعديل (Admin / SuperAdmin) وحذف (SuperAdmin فقط).

## 6. اللوحات (Dashboards)
- [x] **لوحة الإدارة:** عدد المؤلفين، عدد المبيعات، الإيراد الخام، العقود (نشطة/قريبة/منتهية) بنسب، آخر 5 مبيعات، متوسط البيع، إيراد كل مؤلف.
- [x] **لوحة المؤلف:** العقد، إجمالي المبيعات، المصروفات الأساسية، مصروفات العمليات، **صافي الربح**، جدول المبيعات وجدول العمليات (ترقيم مستقل).

## 7. التقارير والتصدير
- [x] تقرير كل المبيعات (Word).
- [x] تقرير كل العمليات (Word).
- [x] تقرير مؤلف تفصيلي (Word + **PDF حقيقي**) للمؤلف نفسه أو للإدارة.
- [x] تقارير كل المبيعات وكل العمليات بصيغة PDF أيضاً (ملف A4 عربي RTL بترقيم صفحات).
- [x] ترميز HTML لكل النصوص المُدخلة داخل تقارير Word (منع حقن HTML).
