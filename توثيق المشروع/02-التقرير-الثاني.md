# التقرير الثاني — تحليل عناصر النظام المقترح

**المعهد العالي للحاسبات ونظم المعلومات الإدارية — المادة: تصميم برامج الحاسب الآلي**
**إعداد:** زياد إسلام محمد علي (202410104) — **إشراف:** أ.د/ فاروق إبراهيم متولي

---

## 1. نظرة عامة على النظام المقترح

النظام المقترح (`AlAsma.Admin`) يحوّل الدورة المالية لدار النشر إلى دورة رقمية:

`مؤلف + عقد` ← `عمليات بيع` ← `مصروفات وعمليات تشغيلية` ← `حسابات الربح` ← `لوحات وتقارير`

---

## 2. المدخلات (Inputs)

| # | المدخل | مصدره | الجهة المدخِلة | التحقق (Validation) |
|---|---|---|---|---|
| 1 | **كود المستخدم وكلمة المرور** | شاشة الدخول | الجميع | مطلوب؛ الكود ≤ 50، كلمة المرور ≤ 100 حرف |
| 2 | **بيانات المؤلف:** الاسم، الكود، كلمة المرور، بداية العقد، نهاية العقد، المصروفات الأساسية `BasicFees` | نموذج إضافة/تعديل مؤلف | SuperAdmin | الاسم مطلوب ≤ 100؛ الكود مطلوب وفريد ≤ 50؛ كلمة المرور ≥ 6؛ `BasicFees` ≥ 0 |
| 3 | **بيانات المدير (Admin)** (نفس حقول المؤلف) | نموذج إضافة/تعديل مدير | SuperAdmin | كما أعلاه؛ الدور يُثبَّت `Admin` من الخادم |
| 4 | **عملية بيع:** اسم الكتاب، المؤلف، سعر البيع، الكمية، المصروفات للنسخة، المنفذ، تاريخ البيع | نموذج تسجيل عملية جديدة | Admin / SuperAdmin | الكتاب مطلوب ≤ 200؛ المؤلف مطلوب؛ السعر > 0؛ الكمية ≥ 1؛ المصروفات ≥ 0؛ المنفذ مطلوب ≤ 200 |
| 5 | **عملية تشغيلية:** بيان العملية، الكتاب (اختياري)، المؤلف (اختياري)، تكلفة الوحدة، الكمية | نموذج إضافة عملية | Admin / SuperAdmin | البيان مطلوب ≤ 255؛ التكلفة ≥ 0؛ الكمية ≥ 1 |
| 6 | **معايير البحث:** نص البحث `q` + حقل البحث `field` + رقم الصفحة | شريط البحث | Admin / SuperAdmin | حقول البحث محددة مسبقاً |
| 7 | **قيمة المصروفات الجديدة (تعديل جماعي)** | نافذة «تعديل المصروفات» | SuperAdmin | قيمة رقمية، تُطبَّق على السجلات المطابقة للبحث الحالي |
| 8 | **طلبات التصدير** (Word / PDF) + معرف المؤلف | أزرار التصدير | حسب الدور | المؤلف يُصدّر تقريره فقط |
| 9 | **تأكيد الحذف** | صفحات تأكيد الحذف | SuperAdmin | نموذج محمي بـ Anti-Forgery Token |

**مدخلات تلقائية (يولدها النظام):** `Id`، `CreatedAt`، `UpdatedAt`، `TotalAmount`، `OperationDate`، حالة العقد والأيام المتبقية.

## 4. العمليات (Processes)

1. تسجيل الدخول والتحقق من كلمة المرور وبناء جلسة بالدور.
2. إدارة المديرين (إضافة / تعديل / حذف ناعم).
3. إدارة المؤلفين (إضافة / تعديل / حذف ناعم) وحساب حالة العقد.
4. إدارة المبيعات (إضافة / تعديل / حذف / بحث / تعديل جماعي للمصروفات) وحساب `TotalAmount`.
5. إدارة العمليات التشغيلية (إضافة / تعديل / حذف / بحث) وحساب `TotalAmount`.
6. حساب المؤشرات واللوحات (إدارة / مؤلف).
7. توليد التقارير وتصديرها.
8. إدارة الصلاحيات (منع الوصول غير المصرح به).
9. معالجة الأخطاء وعرض رسائل مناسبة.

التفصيل الكامل في جدول توصيف العمليات (القسم 8).

## 8. جدول توصيف العمليات (Process Specification)

| الرمز | اسم العملية | الوصف | المدخلات | المعالجة / القاعدة | المخرجات | الجداول | المنفِّذ |
|---|---|---|---|---|---|---|---|
| **P1** | تسجيل الدخول | التحقق من هوية المستخدم | Code, Password | البحث بالكود (غير محذوف) ← `BCrypt.Verify` ← بناء Claims (Id, Name, Role, Code) ← كوكي 8 ساعات | تحويل للوحة الدور أو رسالة خطأ | Authors | الجميع |
| **P2** | تسجيل الخروج | إنهاء الجلسة | — | `SignOut` | صفحة الدخول | — | الجميع |
| **P3** | إضافة مدير | إنشاء حساب Admin | AuthorCreateDto | كود فريد؛ `Role="Admin"` ثابت؛ BCrypt | مدير جديد | Authors | SuperAdmin |
| **P4** | تعديل/حذف مدير | تحديث أو حذف ناعم | AuthorEditDto / Id | كلمة المرور تتغير فقط لو أُدخلت؛ `IsDeleted=true` | تحديث | Authors | SuperAdmin |
| **P5** | إضافة مؤلف | إنشاء حساب Author | AuthorCreateDto | كود فريد؛ `Role="Author"`؛ BCrypt | مؤلف جديد | Authors | SuperAdmin |
| **P6** | تعديل مؤلف | تحديث بيانات | AuthorEditDto | لا يتغير الكود ولا الدور | تحديث | Authors | SuperAdmin |
| **P7** | حذف مؤلف | حذف ناعم | Id | `IsDeleted=true` (تبقى مبيعاته وتظهر «بدون مؤلف») | تحديث | Authors | SuperAdmin |
| **P8** | حساب حالة العقد | تحديد الحالة والأيام | ContractEnd | `days=(End−الآن)`؛ ≤0 منتهي؛ ≤20 ينتهي قريباً؛ غير ذلك نشط؛ فارغ غير محدد | ContractStatus, DaysRemaining | Authors | تلقائي |
| **P9** | إضافة بيع | تسجيل عملية بيع | SaleCreateDto | التحقق من المؤلف؛ `TotalAmount = max(0, السعر×الكمية − المصروفات×الكمية)` | سجل Sales | Sales, Authors | Admin / SuperAdmin |
| **P10** | تعديل بيع | تعديل بيانات بيع | SaleCreateDto | إعادة حساب `TotalAmount` | تحديث | Sales | Admin / SuperAdmin |
| **P11** | حذف بيع | حذف نهائي | Id | Hard Delete | — | Sales | SuperAdmin |
| **P12** | تعديل جماعي للمصروفات | تغيير `BasicExpenses` لمجموعة | q, field, newBasicExpenses | تحديث SQL واحد لكل المطابق + إعادة حساب `TotalAmount` | عدد السجلات المعدلة | Sales | SuperAdmin |
| **P13** | بحث وترقيم المبيعات | عرض صفحة من المبيعات | page, q, field | فلترة وعدّ وجمع وترقيم داخل SQL (10 في الصفحة) | قائمة + مؤشرات | Sales ⟕ Authors | Admin / SuperAdmin |
| **P14** | إضافة/تعديل عملية | تسجيل مصروف تشغيلي | OperationCreateDto | `TotalAmount = ExpenseAmount × Quantity`؛ التحقق من المؤلف إن وُجد | سجل Operations | Operations | Admin / SuperAdmin |
| **P15** | حذف عملية | حذف نهائي | Id | Hard Delete | — | Operations | SuperAdmin |
| **P16** | مؤشرات لوحة الإدارة | حساب المؤشرات | — | `TotalRevenue = Σ(SalePrice×Quantity)` (قبل المصروفات)؛ عدّ العقود الثلاثة | AdminDashboardDto | Sales, Authors | Admin / SuperAdmin |
| **P17** | مؤشرات المؤلف | حساب أرباح المؤلف | AuthorId | `NetProfit = Σ TotalAmount − BasicFees − Σ مصروفات العمليات` | AuthorDashboardDto | Sales, Operations, Authors | المؤلف / الإدارة |
| **P18** | مؤشرات العمليات | حساب مصاريف وأرباح | q, field | `الإجمالي = Σ العمليات + Σ(BasicExpenses×Quantity)`؛ `الربح = Σ(SalePrice×Quantity) − الإجمالي` | KPIs | Operations, Sales | Admin / SuperAdmin |
| **P19** | تصدير تقرير | توليد ملف | AuthorId أو لا شيء | Word: بناء HTML عربي RTL مع ترميز آمن للنصوص ← `.doc`؛ PDF: توليد مستند A4 RTL بمكتبة QuestPDF ← `.pdf` | ملف | Sales, Operations | حسب الدور |
| **P20** | فحص الصلاحية | منع غير المصرح | الطلب + الدور | `[Authorize(Roles=...)]` على الـ Controller والأكشن | السماح أو `/Account/AccessDenied` | — | تلقائي |
| **P21** | حفظ التواريخ تلقائياً | `CreatedAt/UpdatedAt` | الكيان | `override SaveChangesAsync` | القيم | الكل | تلقائي |
