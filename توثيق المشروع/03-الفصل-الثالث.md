## 1. الخوارزميات (Algorithms)

### الخوارزمية 1 — تسجيل الدخول

**المدخلات:** `Code`, `Password` — **المخرجات:** جلسة مستخدم بدور، أو رسالة خطأ.

1. استقبل `Code` و `Password` من النموذج.
2. إذا كانت البيانات ناقصة (ModelState غير صالح) ← أعد عرض النموذج برسائل التحقق.
3. ابحث في `Authors` عن سجل `Code = المُدخل` و `IsDeleted = false`.
4. إذا لم يوجد ← أضف الخطأ «كود أو كلمة مرور غير صحيحة» وأعد النموذج.
5. قارن `Password` بالـ Hash المخزن باستخدام `BCrypt.Verify`. إذا لم تتطابق ← نفس رسالة الخطأ (دون كشف أيهما الخطأ).
6. أنشئ Claims: `NameIdentifier=Id`, `Name`, `Role`, `Code`، وسجّل الدخول بالكوكي.
7. حوّل المستخدم حسب الدور: SuperAdmin ← `/SuperAdmin`، Admin ← `/Admin`، Author ← `/Author`.

### الخوارزمية 2 — تسجيل عملية بيع وحساب الإجمالي

**المدخلات:** `BookTitle, AuthorId, SalePrice, Quantity, BasicExpenses, StoreLocation, SaleDate` — **المخرج:** سجل `Sales`.

1. تحقق من القواعد: السعر > 0، الكمية ≥ 1، المصروفات ≥ 0، الحقول المطلوبة موجودة.
2. إذا فشل التحقق ← اعرض الأخطاء ولا تحفظ.
3. اقرأ المؤلف بالمعرف؛ إذا لم يوجد أو كان محذوفاً ← ارفض العملية برسالة.
4. احسب `الإيراد = SalePrice × Quantity`.
5. احسب `المصروفات = BasicExpenses × Quantity`.
6. احسب `TotalAmount = max(0, الإيراد − المصروفات)`.
7. أنشئ السجل واحفظه (يضبط `CreatedAt` و`UpdatedAt` تلقائياً).
8. اعرض رسالة نجاح وارجع لقائمة المبيعات.

### الخوارزمية 3 — حالة العقد والأيام المتبقية

**المدخل:** `ContractEnd`.

1. إذا كان `ContractEnd` فارغاً ← الحالة «غير محدد».
2. `days = (ContractEnd − الوقت الحالي UTC)` بالأيام.
3. إذا `days ≤ 0` ← «منتهي».
4. وإلا إذا `days ≤ 20` ← «ينتهي قريباً».
5. وإلا ← «نشط».
6. `DaysRemaining = max(0, عدد صحيح(days))`.

### الخوارزمية 4 — صافي ربح المؤلف

**المدخل:** `AuthorId` (من هوية المستخدم لا من الرابط).

1. `إجمالي المبيعات = Σ Sale.TotalAmount` لمبيعات المؤلف.
2. `مصروفات العمليات = Σ Operation.TotalAmount` لعمليات المؤلف.
3. `صافي الربح = إجمالي المبيعات − Author.BasicFees − مصروفات العمليات`.
4. اجلب صفحة (10 سجلات) من المبيعات وصفحة من العمليات مرتبة بالأحدث.
5. ارجع الكائن `AuthorDashboardDto` للعرض.

### الخوارزمية 5 — مؤشرات لوحة الإدارة

1. `عدد المؤلفين = Count(Role="Author")`.
2. `عدد المبيعات = Count(Sales)`.
3. `الإيراد الخام = Σ (SalePrice × Quantity)` (قبل خصم المصروفات).
4. عدّ العقود: نشطة `End > الآن+20 يوم`، قريبة `الآن < End ≤ الآن+20`، منتهية `End ≤ الآن`.
5. آخر 5 مبيعات مرتبة بالتاريخ ثم المعرف تنازلياً.
6. المؤلفون الذين تنتهي عقودهم خلال 20 يوماً.

### الخوارزمية 6 — مؤشرات صفحة العمليات

1. طبّق البحث (`operation | book | author | code`) على العمليات.
2. `مصاريف العمليات = Σ Operation.TotalAmount` (المفلترة).
3. `مصروفات المبيعات = Σ (Sale.BasicExpenses × Sale.Quantity)` (كل المبيعات).
4. `إجمالي المصاريف = (2) + (3)`.
5. `إجمالي المبيعات = Σ (SalePrice × Quantity)`.
6. `صافي الأرباح = (5) − (4)`.

### الخوارزمية 7 — البحث والترقيم (Pagination)

1. `page = max(1, page)`.
2. ابنِ الاستعلام (Sales LEFT JOIN Authors).
3. إذا وُجد نص بحث ← أضف شرط حسب `field` (`book | author | code | store`).
4. نفّذ داخل SQL: `COUNT` + `SUM(TotalAmount)` + `SUM(BasicExpenses×Quantity)` + `SUM(Quantity)`.
5. نفّذ `ORDER BY SaleDate DESC, Id DESC OFFSET (page−1)×10 FETCH 10`.

### الخوارزمية 8 — التعديل الجماعي للمصروفات (SuperAdmin)

1. ابنِ نفس شرط البحث الحالي (`q`, `field`).
2. نفّذ تحديثاً واحداً في SQL: `BasicExpenses = القيمة الجديدة` و `TotalAmount = max(0, SalePrice×Quantity − القيمة×Quantity)` لكل السجلات المطابقة.
3. إذا لم يُحدَّث أي سجل ← رسالة «لا توجد سجلات مطابقة»، وإلا اعرض عدد السجلات المعدلة.

### الخوارزمية 9 — فحص الصلاحية

1. عند أي طلب: اقرأ كوكي الدخول.
2. إذا لم يوجد مستخدم ← حوّل لصفحة الدخول.
3. قارن `Role` بالأدوار المسموحة على الـ Controller ثم على الـ Action.
4. إذا لم يكن مسموحاً ← `/Account/AccessDenied`.

## 2. الشفرة الزائفة (Pseudo Code)

```
// ---------- 1) تسجيل الدخول ----------
FUNCTION Login(code, password)
    IF code IS EMPTY OR password IS EMPTY THEN RETURN ShowErrors
    user ← SELECT FROM Authors WHERE Code = code AND IsDeleted = FALSE
    IF user IS NULL THEN RETURN Error("كود أو كلمة مرور غير صحيحة")
    IF NOT BCrypt.Verify(password, user.PasswordHash) THEN RETURN Error("كود أو كلمة مرور غير صحيحة")
    SignIn(claims = {Id, Name, Role, Code})
    SWITCH user.Role
        "SuperAdmin": REDIRECT /SuperAdmin
        "Admin":      REDIRECT /Admin
        "Author":     REDIRECT /Author
END FUNCTION

// ---------- 2) حساب إجمالي البيع ----------
FUNCTION CalculateTotal(price, qty, expensesPerUnit)
    revenue  ← price * qty
    expenses ← expensesPerUnit * qty
    RETURN MAX(0, revenue - expenses)
END FUNCTION

FUNCTION CreateSale(dto)
    author ← GetAuthor(dto.AuthorId)
    IF author IS NULL OR author.IsDeleted THEN RETURN FALSE
    sale.TotalAmount ← CalculateTotal(dto.SalePrice, dto.Quantity, dto.BasicExpenses)
    INSERT sale ; SaveChanges
    RETURN TRUE
END FUNCTION

// ---------- 3) حالة العقد ----------
FUNCTION ContractStatus(end)
    IF end IS NULL THEN RETURN "غير محدد"
    days ← (end - NOW_UTC).TotalDays
    IF days <= 0  THEN RETURN "منتهي"
    IF days <= 20 THEN RETURN "ينتهي قريباً"
    RETURN "نشط"
END FUNCTION

// ---------- 4) صافي ربح المؤلف ----------
FUNCTION AuthorNetProfit(authorId)
    totalSales ← SUM(Sales.TotalAmount WHERE AuthorId = authorId)
    opsExpense ← SUM(Operations.TotalAmount WHERE AuthorId = authorId)
    fees       ← Authors[authorId].BasicFees
    RETURN totalSales - fees - opsExpense
END FUNCTION

// ---------- 5) صفحة المبيعات ----------
FUNCTION SalesPage(page, q, field)
    page ← MAX(1, page)
    query ← Sales LEFT JOIN Authors
    IF q NOT EMPTY THEN query ← FILTER(query, field, q)        // book | author | code | store
    count    ← COUNT(query)
    revenue  ← SUM(query.TotalAmount)
    expenses ← SUM(query.BasicExpenses * query.Quantity)
    quantity ← SUM(query.Quantity)
    rows     ← query ORDER BY SaleDate DESC, Id DESC SKIP (page-1)*10 TAKE 10
    RETURN (rows, count, revenue, expenses, quantity)
END FUNCTION

// ---------- 6) مؤشرات العمليات ----------
FUNCTION OperationsKpis(q, field)
    opsTotal   ← SUM(Operations(filtered).TotalAmount)
    salesExp   ← SUM(Sales.BasicExpenses * Sales.Quantity)
    gross      ← SUM(Sales.SalePrice * Sales.Quantity)
    totalExp   ← opsTotal + salesExp
    RETURN (totalExp, gross, gross - totalExp)
END FUNCTION
```

## 5. مخطط الكيانات والعلاقات (ERD)

![ERD](<رسومات/03-erd.png>)

| العلاقة | النوع | المفتاح الأجنبي | سلوك الحذف | ملاحظات |
|---|---|---|---|---|
| Authors ← Sales | واحد إلى متعدد (1 : N) | `Sales.AuthorId` | `Restrict` (لا حذف متتالٍ) | المفتاح قابل للإلغاء (NULL)؛ المؤلف المحذوف حذفاً ناعماً تبقى مبيعاته وتُعرض «بدون مؤلف» |
| Authors ← Operations | واحد إلى متعدد (1 : N) | `Operations.AuthorId` | `Restrict` | المفتاح قابل للإلغاء؛ العملية بدون مؤلف تعني «نفقة عامة» |

**ملاحظة:** جدول `Authors` يخزن كل أنواع المستخدمين، والفرق بينهم في العمود `Role`.

## 8. طرق الحساب المعتمدة (من الكود)

| الشاشة | المؤشر | المعادلة |
|---|---|---|
| **السجل الواحد (بيع)** | `TotalAmount` | `max(0, SalePrice×Quantity − BasicExpenses×Quantity)` |
| **السجل الواحد (عملية)** | `TotalAmount` | `ExpenseAmount × Quantity` |
| **لوحة الإدارة** | إجمالي المبالغ | `Σ(SalePrice × Quantity)` — **إجمالي خام (Gross)** قبل خصم المصروفات |
| **صفحة المبيعات** | إجمالي المبالغ | `Σ TotalAmount` — **صافي** بعد خصم مصروفات النسخ |
| **صفحة المبيعات** | إجمالي المصروفات | `Σ(BasicExpenses × Quantity)` |
| **صفحة العمليات** | إجمالي المصاريف الكلي | `Σ Operation.TotalAmount + Σ(Sale.BasicExpenses × Sale.Quantity)` |
| **صفحة العمليات** | صافي الأرباح | `Σ(SalePrice × Quantity) − إجمالي المصاريف الكلي` |
| **لوحة المؤلف** | صافي الربح | `Σ Sale.TotalAmount − Author.BasicFees − Σ Operation.TotalAmount` |

> يوجد نوعان من أرقام المبيعات: **Gross** (قبل الخصم) و**Net** (بعد خصم مصروفات النسخة)، وهذا مقصود حسب متطلبات العميل، ويظهر الفرق بين لوحة الإدارة وصفحة المبيعات.
